Cyber Board

Learn core cybersecurity concepts while solving tactical puzzles. Four randomized, chained stages test your observation and critical thinking.

Code of conduct

  • English only: discuss clues and coordinate in English.
  • Cooperation: both analysts handle the physical board.
  • 3 integrity hearts: at 0, the breach succeeds.

Tabletop setup

  • Place the 4-zone board between both players.
  • Sort Email cards, File grids + punch card and Packet cards.
  • Keep 2 white dice each and the Cipher wheel close.
